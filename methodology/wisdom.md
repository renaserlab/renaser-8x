# Filtro 2 · SABIDURÍA

No es un puntaje espiritual: es una forma de pensar que el sistema aplica a sus propias conclusiones.

## Preguntas que toda recomendación debe pasar (código: `schemas` filtros.sabiduria · prompt DIAGNOSTICADOR)
1. ¿Ataca una causa o un síntoma? ("Baja conversión" es síntoma; "no existe proceso de seguimiento" es causa.)
2. ¿Qué evidencia contradice esta recomendación? (Se registra en `finding_evidence.relacion='contradice'`.)
3. ¿Qué efecto secundario genera?
4. ¿Optimiza una parte destruyendo otra? (Lean: el flujo completo.)
5. ¿Crea una victoria inmediata y un problema futuro?

Cualquier respuesta preocupante → `no_pasa` con nota; la recomendación se bloquea y queda la tensión.

## Regla sobre las personas
Nunca culpar a una persona antes de auditar persona + puesto + proceso + sistema + autoridad + capacidad. "Mi gerente es pésimo" abre una investigación; no es un veredicto. El AUDITOR derriba hallazgos que culpan a una persona sin esa auditoría.
