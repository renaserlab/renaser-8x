# Referentes internos — lentes de investigación

**Regla crítica:** CONOCIMIENTO EXTERNO = LENTE PARA INVESTIGAR. EVIDENCIA INTERNA = PRUEBA PARA CONCLUIR. Nunca convertir un benchmark en un hecho de esta empresa. Ningún nombre de esta lista se muestra al cliente ni aparece en entregables.

Código que los usa: `src/lib/rules/patrones.ts` (`LENTES`) → prompt del DIAGNOSTICADOR. Test de sincronía: `tests/metodologia.test.ts`.

| Referente | Lente | Preguntas que obliga a hacer |
|---|---|---|
| **Marcus Lemonis** | People · Process · Product | People: ¿persona correcta, con responsabilidad, relaciones sanas y desempeño medible? Process: ¿flujo, eficiencia, costo, control, productividad? Product: ¿mercado real, producto, calidad, rentabilidad? |
| **McKinsey** | fact base · organizational health · operating model | ¿Hay base de hechos o solo opiniones? ¿Claridad y accountability por resultado? ¿Capacidades, gobernanza, velocidad de decisión? ¿Dónde se crea valor? ¿Qué sabe la primera línea que la dirección no sabe (frontline insight)? |
| **Alex Hormozi** | oferta y adquisición | ¿Qué problema resuelve? ¿Qué resultado desea el cliente? ¿Qué probabilidad de éxito, velocidad y esfuerzo percibe? ¿La oferta y el precio reflejan ese valor? ¿De dónde vienen los clientes y qué pasa si ese canal muere? ¿Cómo se monetiza? |
| **Steve Jobs / Apple** | foco · simplicidad · experiencia | ¿Qué sobra? ¿Dónde se rompe la experiencia? ¿El producto es integral o un parche? ¿Hay craft? ¿Qué eliminar para ser extraordinario? |
| **Jim Collins** | right people · preserve core / stimulate progress · flywheel · clock building · brutal facts | ¿Las personas correctas en el bus? ¿Qué se preserva siempre y qué se cambia? ¿Existe un flywheel o solo empujones? ¿Se construye el reloj o se da la hora? ¿Qué hecho brutal nadie confronta? ¿Hay propósito más allá del dinero? |
| **Lean** | gemba · flujo de valor | ¿Se observó la realidad o se leyó el manual? ¿Qué paso crea valor y cuál es desperdicio, espera o retrabajo? ¿Mejorar un paso daña el sistema completo? |
| **EOS** | accountability · datos · issues · procesos · prioridades · ejecución | ¿Cada resultado tiene un dueño? ¿Hay datos semanales? ¿Los problemas se resuelven en la raíz? ¿Existen procesos documentados y seguidos? ¿Prioridades trimestrales y cadencia de ejecución? |
| **Propósito / servicio / excelencia** | servicio · integridad · responsabilidad · trascendencia · impacto real | ¿A quién sirve de verdad? ¿Actúa con integridad? ¿Se hace responsable de sus resultados? ¿Deja algo que trasciende? ¿El impacto es real o declarado? |
